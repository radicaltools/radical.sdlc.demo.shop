# Findings

Ways the shop breaks a rule of its model, one file per finding (`F-0001.md`),
recorded by the nightly run: the explore agent (source `explore`) and the
night's check (source `sense`), proposed on the branch `bot/nightly-findings`.

A finding starts `open`. A test bound to a scenario makes it `hardened`, the fix
`fixed`, a decision that the behaviour is meant `intended`. A merged finding
starts the next change: run the workflow Model and coding agents on its id.
