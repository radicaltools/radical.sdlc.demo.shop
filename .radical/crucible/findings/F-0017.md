## Steps

1. place an order (status placed)
2. send POST /orders/{id}/pay twice at the same time

## What differs

```text
Expected: both answers 200 with the order paid, one reservation
Actual: first 200 with reservationId r-6, second 409 {"error":"A paid order cannot become paid"}; a second run gave the same (order o-6, r-10)
Seen: 2 of 2
Where it probably comes from: services/orders/src/server.ts, POST /orders/:id/pay: the paid check and the reserve await come before book.move, so the second request reaches book.move after the first has marked the order paid (guess, from the code path; orderBook.ts check() throws WrongMove)
```
